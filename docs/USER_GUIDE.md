# Короткая инструкция для iPad

## 1. Создать значок приложения

1. Откройте адрес приложения в **Safari** (например, `https://<логин>.github.io/god-v-forme/`).
2. Нажмите «Поделиться» (квадрат со стрелкой) → «На экран „Домой“». Если есть переключатель «Открывать как веб-приложение», оставьте его включённым → «Добавить».
3. Запускайте только с иконки «Год в форме». Данные вкладки Safari и установленного приложения хранятся раздельно.
4. При первом запуске выберите: начать силовые по плану или перенести начало.
5. После первого запуска приложение работает без интернета.

## 2. Отметить тренировку

1. «Сегодня» → карточка «Силовая А» → «Начать тренировку» (или «Тренировки» → нужный день).
2. Нажмите «Техника» у упражнения — два кадра правильного положения, анимация, шаги, ошибки и упрощённый вариант.
3. После каждого подхода нажмите на его кнопку — запустится таймер отдыха (60/75/90 сек, «Пауза», «Завершить»).
4. По желанию впишите фактический вес гири и отметьте «легко / нормально / тяжело» — это поможет ChatGPT через месяц.
5. «Завершить тренировку» → самочувствие → «Сохранить».
6. Нет времени на подробности — просто отметьте кружок у тренировки в списке дня.
7. Нужно перенести — «⋯» → «Перенести на другой день». В статистике это перенос, а не пропуск.

## 3. Посмотреть готовку и закупки

1. «Календарь» → день со значком кастрюли (например, 4 ноября) → «Готовка».
2. Там блюда со ссылками на пошаговые рецепты, продукты, «на какие дни», хранение и чек-лист «После готовки».
3. В дни закупок (1 и 16 ноября) на главной появится «Сегодня закупка» → «Открыть список». Отмечайте «Куплено», при желании впишите фактические цены. Список можно напечатать или скопировать.

## 4. Выгрузить отчёт в ChatGPT (раз в месяц)

1. «Анализ с ChatGPT» → «Отчёт» → проверьте период и что будет передано. Фото по умолчанию не входят.
2. «Выгрузить отчёт за месяц» → «Сохранить или поделиться» → «Сохранить в Файлы».
3. «Скопировать запрос для ChatGPT».
4. В ChatGPT приложите ZIP и вставьте запрос. Попросите прислать файл `plan_update.json`.

## 5. Импортировать обновление от ChatGPT

1. Сохраните `plan_update.json` в «Файлы» (или скопируйте текст JSON).
2. «Анализ с ChatGPT» → «Импорт плана» → «Загрузить обновлённый план от ChatGPT» (или «Вставить текст JSON»).
3. Просмотрите «Было → Станет». Снимите галочки с того, что не подходит. Резкий рост нагрузки нужно подтвердить отдельно.
4. «Применить выбранные». Прошлые отметки, вес и фото не меняются. Если что-то не так — «История» → «Откатить изменения».

## 6. Резервная копия (обязательно)

«Анализ с ChatGPT» → «Резервная копия» → «Создать резервную копию» (по желанию — с паролем) → «Сохранить в Файлы». Делайте копию хотя бы раз в неделю: очистка Safari или удаление значка стирает данные. Тот же файл переносит данные на iPhone: там «Восстановить из копии».

## Обновление приложения

Когда выйдет новая версия, вверху появится «Доступна новая версия» → «Обновить». Ваши данные сохранятся.
